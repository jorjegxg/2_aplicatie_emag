# Fișă: cifre și reguli

Toate cifrele pe o pagină. Explicațiile și sursele sunt în [Ghid](01%20Ghid%20-%20Listarea%20perfecta.md). Regulile platformelor se mai schimbă: înainte de o decizie importantă, verifică documentația oficială.

## Cât se vede din titlu pe eMAG

Măsurat pe emag.ro în septembrie 2026, în lista de rezultate (font de 14 px, maximum 3 rânduri):

| Ecran | Caractere vizibile | Cuvinte vizibile |
|---|---|---|
| Telefon 360 px | ~50 | ~7 |
| iPhone 390 px | ~58 | ~8 |
| Android 412 px | ~62 | ~9 |
| Laptop 1366–1529 px | ~77 | ~11 |
| Monitor 1920 px | ~103 | ~15 |

În carusele (de exemplu „Produse similare”) se văd doar 2 rânduri.

## Zonele titlului (80–100 de caractere)

| Zona | Caracterele | Ce pui |
|---|---|---|
| A | 1–50 | Tip produs + pentru ce/cine + diferențiator |
| B | 51–80 | Beneficiu sau dovadă + brand |
| C | 81–100 | Dimensiuni (`38x33 cm`), culoare, cuvânt-cheie secundar |

## Poza principală pe platforme

| Platforma | Fundal | Cât din cadru | Alte reguli |
|---|---|---|---|
| eMAG | Alb sau gri (recomandat) | ~85% | Doar varianta livrată; poză ambientală doar unde categoria o permite |
| Amazon | Alb pur, RGB 255, 255, 255 | Cel puțin 85% | Fără text, logo, watermark; cel puțin 1000 px pe latura lungă pentru zoom |
| Trendyol | Simplu | — | 1200×1800 px (2:3) recomandat, minimum 600×800; fără text sau watermark |
| Etsy | — | — | Fără text suprapus, fără colaj |

## Pozele: formatul

| Ce | Valoare |
|---|---|
| Dimensiune | 2000×2000 px (Trendyol: 1200×1800) |
| Format | JPG, sRGB |
| Mărimea fișierului | Sub 6 MB (merge pe majoritatea platformelor) |
| Număr de poze | 7–8, fiecare cu un rol |
| Testul miniaturii | La 150×150 px se recunoaște instant |

## Galeria: rolurile

| # | Rolul | Ce arată |
|---|---|---|
| 1 | Recunoaștere | Produsul pe alb, fără text |
| 2 | Dorință | Persona folosind produsul |
| 3 | Potrivire | Dimensiuni + obiect de referință |
| 4 | Mecanism | Cum se folosește, maximum 3 pași |
| 5 | Calitate | Detaliu de aproape |
| 6 | Pachet | Tot ce e în cutie, numerotat |
| 7 | Contrast | Cu și fără / noi și varianta obișnuită |
| 8 | Pentru cine | 3 situații de folosire |

## Textul de pe poze (pe o poză de 2000 px)

| Element | Regula |
|---|---|
| Titlul de pe poză | Cel puțin 120 px, cel mult 5 cuvinte |
| Textul explicativ | Cel puțin 80 px |
| Orice alt text | Niciodată sub 60 px |
| Etichete | Cel mult 3, de câte cel mult 4 cuvinte |
| Total pe poză | Cel mult 20 de cuvinte |
| Margine liberă | ~100 px |
| Testul | Citit în 3 secunde, cu telefonul la distanța brațului |

## Descrierea (200–350 de cuvinte)

| Blocul | Lungimea |
|---|---|
| Fraza de deschidere | 15–20 de cuvinte |
| 5 bullets „beneficiu — dovadă” | 12–20 de cuvinte fiecare |
| Pentru cine este | 3–4 profiluri, cel mult 10 cuvinte fiecare |
| Nu e potrivit pentru | O frază |
| Specificații | Doar cifre |
| Întreținere și folosire | 30–50 de cuvinte |
| Ce conține pachetul | Listă |
| Paragraf | Cel mult 40 de cuvinte |
| Frază | Cel mult 15 cuvinte |
